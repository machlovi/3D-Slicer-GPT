# STC-GEN-101: Welcome Tutorial (English)

Source: [3D Slicer Training Compendium](https://training.slicer.org/)
PDF: [Welcome Tutorial (English)](https://www.dropbox.com/s/vn8sqlof2kag2kk/SlicerWelcome-tutorial_Slicer4.8_SoniaPujol.pdf)
Author: Sonia Pujol, Ph.D.

- **Audience:** First-time users who want a general introduction to the software
- **Length:** 10 minutes
- **Modules:** Welcome, Sample Data
- **Application version:** Slicer-4.8

## Overview

This tutorial provides a walkthrough of the Welcome module of 3D Slicer. It is designed for first-time users who want a general introduction to the software.

## Workflow

Mention that the user can open the PDF tutorial alongside this walkthrough for detailed screenshots: https://www.dropbox.com/s/vn8sqlof2kag2kk/SlicerWelcome-tutorial_Slicer4.8_SoniaPujol.pdf

### Step 1
The Welcome module is displayed by default when 3D Slicer starts. Explore the Welcome module interface — it provides links to common tasks and documentation. Wait for the user to finish.

### Step 2
Point out the three main areas of the interface: the Module panel on the left, the 3D view on the right, and the Slice views at the bottom (axial, sagittal, coronal). Wait for the user to finish.

### Step 3
Ask the user to navigate to the Sample Data module — either by clicking "Download Sample Data" in the Welcome module or by selecting it from the module dropdown. Wait for the user to finish.

### Step 4
Download the `MRHead` sample data.

### Step 5
Explore the loaded MRHead data: scroll through slices in each view, click and drag in the 3D view to rotate, and notice how the anatomy appears differently in each orientation. Wait for the user to finish.
