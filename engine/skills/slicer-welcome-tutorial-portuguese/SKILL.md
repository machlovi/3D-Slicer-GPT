# STC-GEN-101: Tutorial de Boas-Vindas (Portugues)

Fonte: [3D Slicer Training Compendium](https://training.slicer.org/)
PDF: [Tutorial de Boas-Vindas (Portugues)](https://slicerlatinamerica.github.io/media/Tutorials/Welcome_Pt.pdf)
Autora: Sonia Pujol, Ph.D.

- **Publico:** Usuarios iniciantes que desejam uma introducao geral ao software
- **Duracao:** 10 minutos
- **Modulos:** Welcome, Sample Data
- **Versao do aplicativo:** Slicer-4.8

## Visao geral

Este tutorial fornece um passo a passo do modulo Welcome do 3D Slicer. E destinado a usuarios iniciantes que desejam uma introducao geral ao software.

## Fluxo de trabalho

Mencionar que o usuario pode abrir o PDF do tutorial ao lado deste passo a passo para capturas de tela detalhadas: https://slicerlatinamerica.github.io/media/Tutorials/Welcome_Pt.pdf

### Etapa 1
O modulo Welcome e exibido por padrao quando o 3D Slicer e iniciado. Explorar a interface do modulo Welcome — ela fornece links para tarefas comuns e documentacao. Aguardar que o usuario termine.

### Etapa 2
Apontar as tres areas principais da interface: o painel de modulos a esquerda, a visualizacao 3D a direita e as visualizacoes de fatias na parte inferior (axial, sagital, coronal). Aguardar que o usuario termine.

### Etapa 3
Pedir ao usuario para navegar para o modulo Sample Data — clicando em "Download Sample Data" no modulo Welcome ou selecionando-o na lista de modulos. Aguardar que o usuario termine.

### Etapa 4
Baixar os dados de exemplo `MRHead`.

### Etapa 5
Explorar os dados MRHead carregados: rolar pelas fatias em cada visualizacao, clicar e arrastar na visualizacao 3D para girar, e observar como a anatomia aparece de forma diferente em cada orientacao. Aguardar que o usuario termine.
